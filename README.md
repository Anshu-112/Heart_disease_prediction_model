# ❤️ Heart Stroke Risk Predictor

A Machine Learning web application that predicts the risk of heart disease based on clinical health parameters.

## 🚀 Features

- 🩺 Heart disease risk prediction
- 🤖 K-Nearest Neighbors (KNN) model
- 📊 Interactive risk visualization
- 📚 Feature glossary and model explanation
- 🌐 Streamlit web application

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Plotly
- Streamlit

🧠 Model
The project uses a K-Nearest Neighbors (KNN) classification model trained on the Heart Failure Prediction Dataset containing 918 records and 11 clinical features.

The trained model, scaler, and feature information are stored using Joblib.
